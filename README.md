# Six Sigma DMAIC — Retail Checkout Waiting Time Reduction

## Project Overview
This repository contains my independent Six Sigma portfolio project applying the DMAIC (Define–Measure–Analyze–Improve–Control) methodology to investigate and reduce long checkout waiting times in a retail clothing store.

The project is based on direct observation of a real checkout process during peak shopping hours. Since access to the retailer's actual operational data wasn't available, a dataset was built using realistic values derived from these observations, and used to demonstrate the DMAIC methodology end-to-end.

## Problem

During peak shopping hours, particularly weekends and public holidays between 5:00 PM and 8:00 PM, customers experienced excessive waiting times at the checkout counters. Customers were observed waiting up to 12–13 minutes during peak rush; the dataset built from these observations averaged 10.29 minutes for the billing process. Only two billing counters were active, and each cashier handled scanning, tag removal, folding, packing, and payment single-handedly, creating a bottleneck.

## Project Objectives

* Analyse the observed retail checkout process during peak shopping hours
* Identify the primary bottleneck causing long customer wait times
* Apply root cause analysis tools to isolate contributing factors
* Develop a data-driven improvement plan
* Communicate findings and recommendations through professional technical documentation

## Project Deliverables

**DMAIC Report — Reducing Customer Checkout Waiting Time**
Prepared a full technical DMAIC report based on direct observation and a supporting dataset of 35 customer transactions during peak hours. The report included:

* Project charter and problem statement (Define)
* KPI baseline: queue length, waiting time, billing time, packing time (Measure)
* Scatter analysis, process mapping, Fishbone diagram, and 5 Whys root cause analysis (Analyze)
* Improvement recommendations prioritized via Impact–Effort Matrix (Improve)
* KPI targets, monitoring plan, and ownership for sustaining gains (Control)

**Dataset & KPI Analysis**
Compiled and analysed a checkout dataset in Excel, built using realistic values derived from direct observation, including:

* Transaction-level data (queue length, items, billing time, wait time)
* Current vs. expected KPI comparison
* Supporting charts used in the report
